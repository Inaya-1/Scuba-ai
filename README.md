# Scuba.ai
An AI dive buddy housed in a waterproof smartphone case that uses the camera and microphone to keep divers safe, oriented, and educated in real-time.

App: https://scuba-ai.uc.r.appspot.com/

Project page for [Gemini Live Agent Challenge]([url](https://geminiliveagentchallenge.devpost.com/)): https://devpost.com/software/scuba-ai/
