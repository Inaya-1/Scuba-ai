# Cached Dive Maps

Place dive site map images here (JPG/PNG):

- `reef-cove.jpg` — Shallow reef site map
- `blue-hole.jpg` — Deep wall dive map
- `wreck-site.jpg` — Shore entry wreck dive map

These appear in the in-app Dive Map Gallery for quick selection.
Hand-drawn maps on paper also work great — just photograph them with the Upload option.
